# Fictional dental clinic fixture

> Historical V0 fixture. The working V1 NOVA DENTAL examples live in `demos/`, with context in `context/` and records in `data/`.

These context, token and appointment files establish the example project's input. All names, records and scenarios are fictional. The example does not give medical advice.

The functional booking prototype and in-app example loader are planned for later phases. There is no executable example in Phase 1, and these files are not an implemented import format.

Target demonstration: generate a three-step booking flow, interact with it, request two steps, save both versions, duplicate an alternative, restore the original and reopen after restart. It must demonstrate slot conflicts, required inputs and confirmation without a backend connection from the preview.
