# Terminology

**Operatory:** a treatment room with a defined set of supported procedures.

**Slot:** a start time at which both a suitable provider and operatory are available for the entire appointment duration.

**Emergency assessment:** a fictional 30-minute booking type; not a clinical triage decision.

**Urgent treatment:** a fictional 60-minute scheduling type.

**Exploration / alternative:** an independent prototype folder with a parent relationship. It does not replace the original.
