# Playground V1

Playground is the visual workbench; the user's existing coding agent modifies the shared local repository. No provider, API key, embedded chat, account, or AI service is part of V1.

The core loop is local source edit → filesystem watch → successful compilation → automatic interactive preview update. Demos, product context, reusable components, states and feedback are ordinary readable files. SQLite only retains appearance preferences.

Navigation: All Demos, Start Here, Design System, My Demos. Ship three fictional NOVA DENTAL explorations: Current Booking, Simplified Booking, and Patient Search. Designers can interact, jump to declared screens/states, create an independent alternative, return to the original and reopen after restarting.

Implement and verify this loop first. Controls that rewrite configuration and element-level feedback editing are deferred; sample feedback is readable now. No universal editor, cloud service, collaboration, deployment or agent proxy infrastructure.

This definition supersedes the prior V0 implementation plan and AI-provider decisions. Historical research remains for reference, not implementation direction.
